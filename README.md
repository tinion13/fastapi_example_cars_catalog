# Cars Catalog

Тестовый backend-проект на **FastAPI**, демонстрирующий асинхронную работу с бд.


## Что реализовано

- Авторизация, регистрация
- Роутер пользователя
   - Фильтрация и сортировка для каталога
   - Вопрос админу
   - Добавление в избранное
- Роутер админа
   - Изменение, добавление, удаление автомобиля
   - Возможность ответа на вопрос пользователя
- Профиль у пользователей с изменением ника, просмотра избранного

## Стек

- **Python3.12**
- **FastAPI**
- **Uvicorn**
-  **Pydantic**
- **SQLAlchemy**
- **SQLite**
- **aiosqlite**
